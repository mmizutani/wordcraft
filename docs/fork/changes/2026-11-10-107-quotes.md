# A change that quotes what the assistant recalled from past cases says so before you accept it

- **Issue:** #107, AS8.5
- **Upstream doc it would have touched:** `ROADMAP.md`
- **Not verified:** the pane on a real screen; the tests drive it headlessly

A document can talk a model into pasting a past case's fallback position into a tracked change or a comment, and the file may go to the other side. Nothing in the data channel can prevent that, so each output row, when the transcript first sees it and again when its words grow, is checked against what the conversation recalled. A shared run of 36 bytes sets `OutputRow.quotes`, and Details › Output shows "This quotes your case notes" in the warning colour on the row, beside Show, Accept and Reject while it has them and on its own once it is accepted, rejected or resolved: an accepted insertion's words are in the document. The comparison folds case and full-width ASCII with the ranker's own `fold`, and every run of whitespace (spaces, tabs, line breaks, U+00A0, U+3000) to one space, so the two never disagree on what is the same text and a quote reads the same however it was broken across lines or paragraphs.

What the row is checked against is every text the items carried to the model, field by field (terms, what was traded for, traps, guards, how, a balance's factors), not only the line the pane shows for each. The transcript keeps a hash of every 36-byte window of that text, apart from its entries, so trimming an old turn out of the conversation doesn't forget what the model was given. The set holds at most 393,216 windows (64 turns of the 6 KiB recall budget, in ASCII, which has a window at every byte; about 12 MiB when full), and nothing leaves it: an agent session that keeps what it read still holds every item it was sent, and an item it has is not sent again, so dropping an old recall would let a later paste of it pass. When a recall would not fit, it is withheld before its text reaches the turn, and Details says "this conversation has recalled as much as can be checked; start a new one". Checking a row is one hash lookup per window of the row's own text, whatever was recalled, and the row's text is its whole change or comment as far as 8 KiB, not the 120 characters the pane shows: every paragraph of a comment, and every paragraph a change spans, with a line break between paragraphs, which folds to a space on both sides, so a recalled sentence pasted as two paragraphs is a quote and two short paragraphs that read as one only with the break taken out are not. What is indexed is what the turn sent: an item a retaining agent session was given in an earlier turn is not sent again, so it is not indexed again either, and a recall with no run of 36 bytes keeps nothing. A row keeps its flag while only its state changes (accepted, rejected, resolved); replacing its words reads them again, so a quote edited out clears the warning, unless the new words were cut at the 8 KiB kept, where the quote may be past the cut and the flag stays.

It is a flag and not a wall. A paraphrase, a translation, or a run broken inside a word passes, as does a paste past the 8 KiB kept of one change. It looks at what was recalled in this conversation, including earlier turns, and at nothing a person typed.
