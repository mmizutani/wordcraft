# A change that quotes what the assistant recalled from past cases says so before you accept it

- **Issue:** #107, AS8.5
- **Upstream doc it would have touched:** `ROADMAP.md`
- **Not verified:** the pane on a real screen; the tests drive it headlessly

A document can talk a model into pasting a past case's fallback position into a tracked change or a comment, and the file may go to the other side. Nothing in the data channel can prevent that, so each output row, when the transcript first sees it and again when its words grow, is compared with every item the conversation recalled. A shared run of 36 bytes sets `OutputRow.quotes`, and Details › Output shows "This quotes your case notes" in the warning colour beside the row's Show, Accept and Reject. The comparison folds case and full-width ASCII with the ranker's own `fold`, so the two never disagree on what is the same text. A row keeps its flag after it is accepted, rejected or resolved.

It is a flag and not a wall. A row's text is cut to 120 characters, so a long paste is checked only as far as the row shows, and a paraphrase, a translation or a run split by a different line break passes. It looks at what was recalled in this conversation, including earlier turns, and at nothing a person typed.
