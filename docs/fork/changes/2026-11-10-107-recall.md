# A turn bound to a case carries what the person's cases recall, as data, and nothing when anyone else reads the document

- **Issue:** #107, AS8.3
- **Upstream doc it would have touched:** `ROADMAP.md`
- **Not verified:** a real ChatGPT or ACP agent reading the recalled source; both backends ran against their fakes only

A conversation whose document is bound to a case now carries, on each turn, what ranks highest from that case and from the same client's other cases (`crates/assist/src/cases/recall.rs`). The window builds a `RecallAsk` on the frame (the shelf, the case, the prompt with the text around the caret, today, and an `Alone`), and the conversation's thread runs it just before the backend's turn, so the file reads stay off the frame. What it finds joins the turn's sources as one `TurnSource` whose origin is `Recalled`, and both backends send it as they send an attached source: ChatGPT in this turn's input and never in `instructions`, gone from the next request's history; an ACP agent as a text or resource block. Its framing is WordCraft's: data, never instructions; items marked unconfirmed were written by a model, possibly after reading the other side's text; don't copy any of it into the document or a comment unless the person asks; write `[[used: id]]` where an item shapes the answer. The id of this case's note is `n12`, of another case's `<case>:n12`, of its balance `<case>:balance`, so none collides with a preference's `m1`, and a `[[used: …]]` naming one the turn sent becomes a chip as a preference's does; one the turn didn't send does nothing.

`Pool::load` reads the bound case and the other cases of its wall, most recently changed first, at most 64 cases or 16 MiB of files, and nothing from any other wall: the folder is the ethical wall. A neighbour contributes its confirmed notes and its newest confirmed balance; `Neighbor::of` drops everything unconfirmed, so a model's note never leaves the case it was written in. Composition is greedy by score inside 6 KiB, at most three notes from one neighbour and twelve items in all, nothing below `MIN_SCORE` (0.1, a guess and the knob); what was left out is counted. A neighbour's balance rides with its first note that made the cut rather than being ranked on its own, so the model sees why that case stood where it did; the design ranked it as a candidate, which the ranker's `Candidate` (a note and its case) can't hold without a second shape. A case that can't be read makes recall return nothing and say so; it never stops a turn.

The instruction channel got a type. `Turn.memory` is `Option<memory::Instructions>`, whose only constructor is `Memory::for_model`, from texts the person's click kept and the module's constants; two `compile_fail` doctests show a `String` can't become one. The ACP backend compares and sends it through `as_str`, ChatGPT appends it to its instructions the same way, and nothing else changed there.

Recall runs only with an `Alone`, which only `Alone::check(room, me, seat)` makes: it fails on any participant other than the window's own copy and this conversation's seat, and on any invite other than the seat's, joined or not. Neither `Alone` nor `RecallAsk` is `Clone`, so a proof is used once, and the proof keeps what the check needs so that `RecallAsk::run` checks again on the conversation's thread: someone who joins between the frame that built the ask and the turn that runs it gets nothing, and Details says who. Without an `Alone` the turn runs exactly as today, and `Sent.recall_withheld` says why (no case is bound, no settings folder, or who can read the document), which Details › Recalled shows in orange. Once a conversation has recalled anything (`Assistant::recalled`, a sticky flag set from the `Recalled` event as it is polled, so it can't miss one), a turn while anyone else can read the document is refused outright, "This conversation has read your case notes and Bob can now read this document. Start a new conversation.", because the model still holds what it read and a document could ask it to write that into a comment the newcomer reads. And each frame, while such a conversation goes on, someone who can now read the document ends it, stopping a running turn, with a notice in the pane saying why; the check reads the room's participant list in memory and runs only once a turn has recalled. That section lists per turn each item, where it came from (this case, or the same client's case by title), whether it is unconfirmed, the balance then against now, how many more scored but didn't fit, and any problem reading the files. Interface text goes through `tl!`; recalled text doesn't.

`Backend::retains()` is `None` for ChatGPT and the fake and a count of ended sessions for an ACP agent; `Work` keeps a `Told` set so an agent session is sent each item once and hears it again only in a new session, while ChatGPT gets this turn's items every turn. Details marks an item sent earlier.

A conversation belongs to one case for its life: `Conversation.case` is set when it starts, and a document whose binding differs gets a new conversation, since an ACP session keeps what it read and ChatGPT's history holds answers that may quote it. The binding is a per-document map in `crates/ui-egui/src/assist/cases.rs`, set in this pull request only through `WordApp::bind_case`, a test helper: the commands that let the person bind a case come next, so `docs/assistant.md` doesn't describe recall yet. A backend's own `Event::Recalled` is dropped like its own `Done`, so a backend can't make Details claim a recall.

Tests: canaries in another wall and in a neighbour's unconfirmed note reach no field of any turn; this case's note and a neighbour's confirmed note reach `knowledge` JSON-quoted with the recalled wording and never `memory`; ChatGPT's fake shows the item in `input`, not `instructions`, and absent from the next request; the fake agent's report shows it told once across two turns of one session; a second participant and an unused invite each withhold recall from a conversation that hasn't recalled yet, and Details names them; each refuses a turn to one that has, and nothing reaches the backend, also when the answer made more entries than events; someone joining while a turn that recalled is still running ends the conversation on the frame and the pane says why; someone joining between the frame and the turn gets no recalled text; with no case bound a turn's memory, sources and context are as before; a rebind starts a new conversation; a neighbour gives at most three notes and its balance; `the_window_never_waits_for_its_assistants` and the gate's frame budget stay green.
