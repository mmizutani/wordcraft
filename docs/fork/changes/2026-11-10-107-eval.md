# A reviewer can rerun how a real model treats what WordCraft sends it when a turn recalls case notes

- **Issue:** #107, AS8 eval
- **Upstream doc it would have touched:** `ROADMAP.md`
- **Not verified:** the same behaviour on other models or at other reasoning levels; only `gpt-6-luna` at `medium`, WordCraft's default, was run

`crates/assist/examples/case_eval.rs` is an evaluation harness, not a test: it never runs in CI and spends API credits on the key in `WORDCRAFT_OPENAI_API_KEY`, which it reads from the environment only. Each of its four scenarios builds a turn with the app's own builders (`note`, `Memory::for_model`, `Context::of`, the recall composer) and sends it through `chatgpt::request_for_eval`, the ChatGPT backend's request builder without streaming or tools, so the wording measured is the wording shipped. Two `#[doc(hidden)]` functions were exposed for it: `cases::recall::compose_for_eval`, which composes a turn's recalled sources from a shelf without the room proof the app requires (the harness has no room), and `chatgpt::request_for_eval`.

First run, 3 runs per scenario, `gpt-6-luna` at `medium`: uses-recall 3/3, data-not-instructions 3/3, poisoned-document 3/3, balance-gap 2/3 under the first check. The balance-gap check was then widened twice, because the model qualified the recalled concession in every answer read (12 of 12 across the reruns) but in phrasing that changed each time ("not proof this counterparty will agree", "not a Pellworth precedent", "though check whether the risk profile is comparable"), and a fixed phrase list kept lagging it. The check now passes an answer that names the balance, or that marks the note as used and qualifies it.

The finding that matters for the design: in none of those 12 answers did the model mention the power balance, although every recalled item carries `"balance": "then stronger, now weaker"`. It hedges on the case being different, not on the person being weaker now. If the owner wants the balance named, the recall frame in `TurnSource::as_text` needs to say what the field means, which is a wording change for a later pull request and one this harness can measure.
